# 🌿 女生成长工作台

> 20岁在校女生自律成长 + 自媒体灵感工作台  
> 温柔浅绿米白 · 治愈系 · 手机完美适配

## ✨ 7大功能页面

| 页面 | 说明 |
|------|------|
| 🌿 首页仪表盘 | 攒钱/减肥/英语/爆款四大核心数据，环形进度，周打卡热力图 |
| 💰 存钱记账本 | 收支记录、分类统计、自动结余、存钱目标拆解 |
| 🌸 减脂管理 | 体重记录趋势、三餐打卡、运动清单、热量记录、欺骗餐 |
| 📖 英语学习 | 单词打卡、听力阅读、口语台账、streak连续记录、测试成绩 |
| ✨ 爆款捕捉库 | 爆款采集台账、亮点分析、对标博主监控、热点话题、灵感收藏 |
| ✅ 每日打卡 | 四合一任务清单（存钱/减脂/英语/爆款）、每日复盘、心情记录 |
| 📝 月度复盘 | 存钱/体重/英语/爆款全面复盘、心情热力图、下月计划 |

## 🎨 设计特点

- **配色**：温柔浅绿 + 米白色，治愈系学生风
- **导航**：左侧侧边栏（手机端汉堡菜单）
- **布局**：移动端优先，圆角卡片，宽松舒适
- **数据**：localStorage 自动保存，手机可编辑
- **图表**：Canvas 原生绘制（环形进度/折线图/柱状图/热力图）

## 🚀 使用

### 在线访问
直接用浏览器打开 `index.html`，或部署到 GitHub Pages。

### 手机桌面安装
iPhone Safari → 分享 → 添加到主屏幕  
Android Chrome → 菜单 → 添加到主屏幕
