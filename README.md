# 💰 1年百万搞钱工作台

> 个人独立创业者目标管控系统 · 深色黑金商务风格

一套完整的7页面工作台，帮助你规划、追踪、复盘年度100万收入目标。

## ✨ 功能页面

| 页面 | 说明 |
|------|------|
| 📊 数据总仪表盘 | 100万目标进度、收益图表、核心指标卡片 |
| 🎯 变现赛道规划 | 3条盈利赛道详细规划、定价、获客、收入测算 |
| 💰 财务记账 | 收入/支出/利润自动统计 |
| 👥 客户管理CRM | 线索→意向→成交→售后全链路管理 |
| ✅ 每日执行打卡 | 日/周任务清单、行动指标打卡 |
| 📈 月度复盘 | 营收复盘、缺口分析、优化计划 |
| 📚 资源库 | 话术、素材、工具链接收纳 |

## 🚀 使用方式

### 本地使用
直接用浏览器打开 `index.html` 即可。

### 在线访问（GitHub Pages）
1. Fork 或上传到你的 GitHub 仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支，目录选 `/ (root)`
4. 保存后等待1-2分钟，即可通过 `https://你的用户名.github.io/仓库名/` 访问

## 🛠 技术栈

- 纯 HTML + CSS + JavaScript（零依赖）
- Canvas 原生图表绘制
- 响应式布局，支持移动端

## 📁 项目结构

```
├── index.html          # 页面1：数据总仪表盘
├── tracks.html         # 页面2：变现赛道规划
├── finance.html        # 页面3：财务记账
├── crm.html            # 页面4：客户管理CRM
├── daily.html          # 页面5：每日执行打卡
├── review.html         # 页面6：月度复盘
├── resources.html      # 页面7：资源库
└── assets/
    ├── style.css       # 共享样式（深色黑金设计系统）
    └── common.js       # 共享脚本（导航、图表、工具函数）
```
